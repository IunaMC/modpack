# Changelog — v2.2.3, Farming Expansion and Modpack Cleanup

## Add
- Add Botany Pots to automate crop and tree growth using specialized planting pots
- Add Botany Trees to extend Botany Pots with automated tree cultivation support
- Add Power Scale to provide configurable power generation and consumption scaling utilities
- Add FallingTree to simplify wood gathering by allowing entire trees to be felled at once
- Add Prickle as a required dependency for newly introduced gameplay content
- Add Silent Lib as a required shared library dependency for supported mods

## Removed
- Remove FTB Chunks following the migration away from the FTB utility ecosystem
- Remove FTB JEI Extras as it is no longer required after removing FTB dependencies
- Remove FTB Library as it is no longer required by the current modpack
- Remove FTB Teams following the removal of the FTB utility suite

## Updated
- Promote Bookshelf from an optional mod to a required dependency
- Update modpack version metadata to `v2.2.3`
- Update the mod list to reflect the current modpack composition
- Add packaging and release assets for the current distribution workflow
